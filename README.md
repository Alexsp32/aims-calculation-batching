# Batch DFT calculation notebooks

These Marimo notebooks might be useful to start a large number of identical DFT calculations for different structures and the pull back the results into the input structure file. 

Make sure to install [Marimo](https://marimo.io) in your python environment

```bash
pip install marimo
```

Then launch the notebooks using either: 

```bash
# Read-only mode - nicer interface but can't edit code. 
marimo run DFT-setup.py
# Edit mode - All code visible, interface a bit more cluttered.
marimo edit DFT-postprocessor.py
```
